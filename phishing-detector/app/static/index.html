Evaluation Integrity & Leakage Prevention

Domain-Grouped Splitting: The dataset is partitioned by registered root domain (GroupShuffleSplit). Variations of the same domain are strictly isolated to either the training or the test set, preventing artificial score inflation from near-duplicate URLs.

Probability Calibration: Raw tree probabilities are calibrated with CalibratedClassifierCV(cv=3, method='sigmoid'), ensuring that an assigned 90% risk probability corresponds directly to empirical risk.

Tranco Top 1k Allowlist Tier: Authoritative top global domains are verified and badged with explicit attribution, rather than hardcoded hacks.

The Anatomy of Modern Phishing Attacks

Understanding attack vectors, deception tactics, and defensive countermeasures.

1. Typosquatting & Lookalike Domains

Attackers register lookalike domains using character substitutions (e.g. paypa1.com or rnicrosoft.com) or Punycode homoglyphs (xn--googl-rsa.com). PhishGuard calculates Levenshtein distance against known target brands to automatically detect these variations.

2. Subdomain Masquerading

In a deceptive URL like chase.com.login-verify.xyz, the real registered root domain is login-verify.xyz. PhishGuard extracts the actual second-level root domain and flags brand names embedded in subdomains.

3. Shorteners & Hidden Redirects

Phishers frequently mask malicious payloads behind URL shorteners like Bitly or TinyURL. PhishGuard expands redirect chains safely with strict SSRF filtering before scoring the final target destination.

4. Proactive Defense Strategies

Always verify the root domain in the address bar before submitting credentials. Use FIDO2/WebAuthn hardware security keys, which cryptographically bind your session to the true origin and neutralize credential phishing proxies.
